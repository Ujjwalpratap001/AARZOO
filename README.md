# AARZOO_2- – UDAAN Productivity & Student Planning App

This repository contains the **UDAAN** application project: a productivity and planning app designed to help users organize daily tasks, upcoming exams, goals, and personal progress. The project is stored in the repository named **AARZOO_2-** and is part of the app-building work of **Ujjwal Pratap**.

> The existing project documentation names the app “UDAAN”. This README keeps that product name clear while connecting it to the AARZOO_2- repository.

## Purpose

UDAAN brings everyday planning tools together in one place so students and other users can manage tasks, remember important dates, and track goals without a complicated setup.

## Features described for the project

- **Dashboard:** overview of tasks, goals, and progress
- **Daily tasks:** add and manage everyday activities
- **Upcoming exams:** save exam names, dates, and related details
- **Goals:** define targets and monitor progress
- **Progress and analytics:** view visual summaries and progress graphs
- **Profile:** manage profile information and preferences
- **Optional setup details:** users can skip personal or academic details and continue

## Getting started

The current project notes describe this user flow:

1. Install and open a supported app build.
2. Continue through the welcome/setup flow.
3. Add personal or academic details only if needed.
4. Create tasks, exams, and goals.
5. Review the dashboard to follow progress.

Availability may vary by app build. No unsupported claim is made here about a public store release or downloadable APK.
